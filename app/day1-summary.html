总体概览

day1 覆盖了核心容器工具（map / set / bound 二分）、提交规范与作业要求，并通过四道例题（校园打卡、机器人扫地、村庄朋友统计、万能密钥）把工具落地，晚上又深入讲解了机器人扫地与朋友统计的实现逻辑。

核心知识点一览

主题关键内容复杂度
map红黑树，键值对，键唯一自动升序；count / [] / insert / eraseO(logN)
set与 map 同底层，仅存唯一键，自动去重排序O(logN)
bound 二分lower_bound ≥目标，upper_bound >目标；二者差 = 出现次数O(logN)
提交规范对比 .in/.out 校验结果；时间分配；文件 ≤ 100 KB—

四道例题要点

题目数据结构解法要点
校园打卡mapmap 存学号-得分，仅首次出现计分
机器人扫地set + 二分灰尘入 set + 墙作哨兵，跳转最近灰尘
村庄朋友统计排序 + 二分按坐标排序后二分定位距离范围，结合学校去重
万能密钥set密钥取反入 set，遍历 0~2²⁰ 找答案

实现逻辑要点

  • 机器人扫地：upper_bound / find 定位、`*it` 解引用、`erase(it)` 删除、`it--` 反向查找、条件外置。
  • 朋友统计：sum1+sum2−sum3 公式；学校编号大用 `map<int, vector<int>>`；排序只对备份数组。
