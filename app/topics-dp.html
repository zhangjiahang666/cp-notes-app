专题 · 动态规划

DP 入门心法 · 最长上升子序列 LIS（朴素 / 二分优化）· LIS 方案与方案数 · 最长公共子序列 LCS · 最长公共子串 · 变种速记

一、DP 入门心法

动态规划的本质是「把大问题拆成重复的小问题，用一张表把小问题的答案存下来」。写对 DP 只需想清四件事：状态定义 → 转移方程 → 初始化 → 遍历顺序。

要素要回答的问题常见写法
状态定义 dp[i]这张表的每一项到底代表什么？「以 i 结尾 / 前 i 个 / 到 i 为止」的值，务必一句话说清
转移方程dp[i] 由哪些更小规模的状态推出？枚举最后一步的所有决策，取 max / min / 求和
初始化边界（i=0 / 空串 / 单独一个元素）是多少？按题意赋 0 / 1 / 极大值，别漏边界
遍历顺序填表时 i 该从左还是从右？保证「用到的更小规模状态」已经算出来
自检口诀：状态说不清 → 方程一定错；方程写得出 → 顺序和初始化再检查一遍。答案往往不是 dp[n]，要在整张表里取 max / 累加（如子序列类）。
判断能不能用 DP：问题有最优子结构（大最优由小最优拼成）且无后效性（算出后不再被前面影响）。

二、最长上升子序列 LIS

状态设计（O(n²) 朴素）

f[i] = 以 a[i] 结尾的最长上升子序列长度。转移：枚举所有 j < i 且 a[j] < a[i]，把 a[i] 接到后面。

项内容
转移方程f[i] = max(f[i], f[j] + 1)，对所有 j < i 且 a[j] < a[i]
初始化f[i] = 1（单独一个元素自身就是长度 1 的上升子序列）
答案max(f[1..n])，不是 f[n]
复杂度时间 O(n²)、空间 O(n)
 
#include <bits/stdc++.h>
using namespace std;
const int N = 5005;
int n, a[N], f[N];

int main() {
    ios::sync_with_stdio(false), cin.tie(0);
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    int ans = 0;
    for (int i = 1; i <= n; i++) {
        f[i] = 1;                         // 至少长度为 1
        for (int j = 1; j < i; j++)
            if (a[j] < a[i])              // 严格上升
                f[i] = max(f[i], f[j] + 1);
        ans = max(ans, f[i]);
    }
    cout << ans << "\n";
    return 0;
}

O(n log n) 二分贪心优化

维护辅助数组 d[k] = 长度为 k 的上升子序列的「最小结尾值」，d 始终单调递增。来了 a[i]：能接上（a[i] > d[len]）就加长；否则用 lower_bound 找到第一个 ≥ a[i] 的位置替换成更小的结尾，给后续元素留出空间。

#include <bits/stdc++.h>
using namespace std;
const int N = 200005;
int n, a[N], d[N];   // d[k]: 长度为 k 的上升子序列的最小结尾值

int main() {
    ios::sync_with_stdio(false), cin.tie(0);
    cin >> n;
    int len = 0;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        if (a[i] > d[len]) {            // 能接在当前最长序列后面
            d[++len] = a[i];
        } else {                         // 找到第一个 >= a[i] 的位置替换
            int pos = lower_bound(d + 1, d + len + 1, a[i]) - d;
            d[pos] = a[i];
        }
    }
    cout << len << "\n";                // len 即为 LIS 长度
    return 0;
}
二分选型速记：严格上升用 lower_bound（找 ≥ x 替换）；不下降（可相等）改用 upper_bound（找 > x 替换）。下降类则把 d 改成维护「最大结尾」并用手写反向二分。

三、LIS 的方案与方案数

输出一组具体方案（前驱记录）

在 DP 过程中多记一个前驱数组 pre[i] = 转移到 i 的那个 j。先找到 f[i] 等于最大长度的任意结尾位置，再沿 pre[i] 一路向前跳，收集后倒序输出，就还原出一条具体的 LIS。

// 在 O(n^2) DP 中追加前驱记录
for (int i = 1; i <= n; i++) {
    f[i] = 1;
    for (int j = 1; j < i; j++)
        if (a[j] < a[i] && f[j] + 1 > f[i]) {
            f[i] = f[j] + 1;
            pre[i] = j;                  // 记录上一个结尾是谁
        }
}
// 还原：挑一个 f[i] == ans 的结尾 id，沿 pre 往前跳
vector<int> path;
for (int i = id; i >= 1; i = pre[i]) path.push_back(a[i]);
reverse(path.begin(), path.end());

统计方案数（计数）

再加一维计数数组 g[i] = 以 i 结尾的 LIS 的方案数。转移时分两种情况：发现更长的子序列就把 g[i] 重置为 g[j]；发现等长的另一条路径就把 g[i] 累加 g[j]。最后对所有 f[i] == 最大长度的 g[i] 求和。

// f[i]: 长度；g[i]: 以 i 结尾的 LIS 方案数
for (int i = 1; i <= n; i++) {
    f[i] = 1, g[i] = 1;               // 每个元素自身是一条长为 1 的方案
    for (int j = 1; j < i; j++)
        if (a[j] < a[i]) {
            if (f[j] + 1 > f[i]) {
                f[i] = f[j] + 1;
                g[i] = g[j];           // 更长：重置为继承的方案数
            } else if (f[j] + 1 == f[i]) {
                g[i] += g[j];          // 等长：累加方案数
            }
        }
}
int sum = 0;
for (int i = 1; i <= n; i++)
    if (f[i] == ans) sum += g[i];     // 所有达到最大长度的方案数相加
计数时要防重复：若存在值相同、长度相同的并列转移，需按题意决定是否去重；否则会把「同一位置的不同写法」算成多条方案。

四、最长公共子序列 LCS

f[i][j] = s[1..i] 与 t[1..j] 的最长公共子序列长度（子序列不要求连续）。二维 DP，时间 O(nm)、空间 O(nm)。

情况转移
s[i] == t[j]f[i][j] = f[i−1][j−1] + 1（两个字符都用上）
s[i] != t[j]f[i][j] = max(f[i−1][j], f[i][j−1])（至少舍掉一个）
初始化f[i][0] = f[0][j] = 0（空串公共子序列为 0）
答案f[n][m]
 
#include <bits/stdc++.h>
using namespace std;
int f[2005][2005];

int main() {
    ios::sync_with_stdio(false), cin.tie(0);
    string s, t; cin >> s >> t;
    s = " " + s; t = " " + t;         // 垫空格，下标从 1 开始
    int n = s.size() - 1, m = t.size() - 1;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            if (s[i] == t[j])
                f[i][j] = f[i - 1][j - 1] + 1;
            else
                f[i][j] = max(f[i - 1][j], f[i][j - 1]);
        }
    cout << f[n][m] << "\n";
    return 0;
}

路径还原思路

从 f[n][m] 出发反向走：若 s[i]==t[j] 则这个字符是公共字符，记下并跳到 (i−1, j−1)；否则往 f 值更大的方向（f[i−1][j] 与 f[i][j−1] 谁大走谁）退一步。收集到的字符再倒序即为一条具体 LCS。

五、最长公共子串（连续版）

子串要求字符连续，与 LCS 的关键区别在于状态含义和「不匹配」的处理。f[i][j] = s 以 i 结尾、t 以 j 结尾的最长公共子串长度。

对比LCS（子序列）最长公共子串
是否连续不要求连续必须连续
s[i] != t[j]max(f[i−1][j], f[i][j−1])，延续f[i][j] = 0，连续链中断归零
答案f[n][m]（右下角）整张表里取 max（可能在中间）
 
// f[i][j]: s 以 i 结尾、t 以 j 结尾的最长公共子串长度
int ans = 0;
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++) {
        if (s[i] == t[j])
            f[i][j] = f[i - 1][j - 1] + 1;
        else
            f[i][j] = 0;             // 不匹配：连续链中断，归零
        ans = max(ans, f[i][j]);     // 答案在全表取最大值
    }

六、变种速记表

同一套「状态 + 二分 + 二维表」思路稍加改造即可覆盖下列变种，记住每个的一句核心转换即可。

变种思路要点（一句概括）
最长上升奇偶子序列把上升条件改为相邻元素奇偶性交替（a[i] 与 a[j] 一奇一偶），其余转移与 LIS 完全相同。
排列的 LCS两序列都是排列时，LCS 可转化为 LIS：把第二个排列映射成「位置」后，对原序列求 LIS 即可。
反向最长公共子序列把其中一个序列反转后再求一次普通 LCS，本质仍是同一套二维 DP。
字母的最长公共子序列限定只能用某几个字母 / 字符集时，先过滤掉无关字符，再对剩余串做标准 LCS。
方法迁移：LIS 解决「单序列 + 顺序约束」，LCS 解决「双序列对齐」；遇到新题先判断属于哪一类，再套用对应模板微调比较条件。
