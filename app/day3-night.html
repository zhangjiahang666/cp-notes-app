一维差分

差分是前缀和的逆运算：对差分数组求前缀和即可还原原数组，可原地修改、无需额外空间。

要点内容
定义B[i] = A[i] - A[i-1]；若 A 是 B 的前缀和，则 B 是 A 的差分数组
区间加区间 [L,R] 整体加 C：只需 B[L]+=C、B[R+1]-=C，O(1) 完成
口诀哪里不对改哪里——仅改对应位置，自动影响后续前缀和
边界需保证 L≤R，若 L>R 则交换两值统一处理
应用海底高铁等区间计数题，避免暴力逐元素 O(n) 修改超时

二维差分

二维差分是二维前缀和的逆运算，可由前缀和公式移项推导，无需单独记忆。

要点内容
维护公式B[i][j] = A[i][j] - A[i-1][j] - A[i][j-1] + A[i-1][j-1]
矩形加矩形 (X1,Y1)-(X2,Y2) 加 C：仅对差分数组四个对应位置做加减，自动抵消重复区域偏差
还原对差分数组求二维前缀和，即可还原更新后的原数组
应用铺地毯等二维区间覆盖/计数题目

二分法

题目出现"求最大/最小"类最值表述时约 80% 优先考虑二分；答案与输入变量存在明确的单调（正比/反比）关系即可用二分，复杂度优化至 O(log n)。

类型要点
整数二分·模板模板固定：确定答案左右边界、设独立变量存答案、构造校验函数 F；仅需调整校验函数适配不同题目。校验函数返回 int 或 bool，推荐 int（可获取具体计算值）。案例：伐木题锯片高度与木材总长成反比（单调），暴力 4×10^11 降至 10^7。
实数二分答案为小数时用 double 边界，避免整数精度丢失；设独立精度变量控制终止，精度比要求保留小数位多一位，或固定循环 60 次。
  • 二分模板千年不变：核心框架固定，构造校验函数是最难一步，多数为模拟逻辑，复杂场景可结合搜索、连通块判断。
  • 单调性：若高度 X 满足需求，则 X 以下均可行；若 X 不满足，则 X 以上均不可行。

课后练习与学习要求

内容核心要点
练习顺序先完成当日错题订正，未订正不得提前写后续练习题；订正后先完成差分 D3 第一题，再推进第二题，可额外练习二维差分"铺地毯"。
备考方向陕西省级一等奖难度不高，核心为熟练掌握基础算法实现与应用场景，靠高频练习巩固。
编码规范注意变量范围与边界判断，不得依赖"可能不会报错"的侥幸心理，避免数组越界、数值溢出。
