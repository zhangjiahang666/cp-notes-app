专题 · 周赛方法论

应试策略 · 高频套路速查（信号 → 方法）· 二分答案 / 前缀和差分模板 · 对拍与调试 · 易错点清单 · 提交规范

本页不收录任何具体场次题解，只整理周赛 / 模拟赛通用的应试策略与方法论套路：先把比赛当成一场流程来打，再用速查表快速识别题型、套通用模板。

一、周赛 / 模拟赛应试策略

读题顺序：先全卷扫一遍再动手

开赛后先用 5~10 分钟把所有题目快速通读（看数据范围、判断难度、标记关键词），在脑子里给每题排个难易序，不要拿到第一题就死磕。

阶段做法目的
扫卷（前 10 分钟）通读全部题 + 数据范围，标记「一眼能做 / 需要想 / 难」建立全局视图，避免错过后面的送分题
顺序（先易后难）按「最有把握拿分」的顺序做，不按题号死做先把稳分拿到手，建立信心
卡题限时单题想不超过 ~20 分钟没思路就先跳过，做个记号防止被一题锁死、浪费整场时间
收尾回头啃跳过的题 + 复查已 AC 题的边界把能捞的分都捞回来
时间分配口诀：先易后难、卡题就跳、样例必跑、边界必查。一道题想得再漂亮，不如先把确定能拿的分拿到。

二、高频套路速查表（识别信号 → 用什么方法）

读题时先抓识别信号，再对号入座选方法。下表是周赛最常见的几类，别一上来就上复杂算法。

题型识别信号用什么方法
模拟按题意一步步操作，规则描述很细直接按题意实现，重点抠细节（顺序、下标、边界）
枚举 / 暴力数据范围很小（如 n ≤ 20）暴力枚举所有情况，能过就行，别过度优化
贪心每次选局部最优即可、可证交换后不会更差按某个关键字排序后依次取；区间类按右端点排序
二分答案求「最大的最小 / 最小的最大」，答案随某变量单调二分答案区间 + 写一个 check(x) 判定函数
前缀和 / 差分多次区间求和，或多次区间整体加/减前缀和 O(1) 查区间和；差分 O(1) 做区间修改
栈 / 队列括号匹配、成对消除、单调结构、滑动窗口栈模拟配对；单调栈 / 单调队列维护极值
贪心证明小技巧——邻项交换法：假设相邻两个方案顺序交换，比较结果哪个更优，由此推出应按什么关键字排序（如加工时间短的任务先做，总等待时间更小）。

三、通用模板代码

二分答案模板（整数）

适用：答案具有单调性（x 可行则更小/更大的也可行）。核心是把「求答案」转化为「判定答案 x 是否可行」。

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// check(x)：判断答案为 x 时是否可行（按题目自定义）
// 单调性：x 越大越容易可行，则求「最大可行值」
bool check(ll x) {
    // 在这里写判定逻辑，返回 true 表示 x 可行
    return true;
}

int main() {
    ll lo = 1, hi = 1e9, ans = lo;   // 上下界按题意取足
    while (lo <= hi) {
        ll mid = (lo + hi) / 2;
        if (check(mid)) { ans = mid; lo = mid + 1; }  // 可行：记录并尝试更大
        else             { hi = mid - 1; }            // 不可行：往小收
    }
    cout << ans << "\n";
    return 0;
}

前缀和 / 差分模板

前缀和把多次区间求和降到 O(1)；差分把多次区间整体加减降到 O(1)，最后求一次前缀和还原。

#include <bits/stdc++.h>
using namespace std;
const int N = 100005;
int a[N], s[N], d[N];   // a 原数组, s 前缀和, d 差分数组

int main() {
    int n, q; cin >> n >> q;
    for (int i = 1; i <= n; i++) cin >> a[i];

    // 前缀和：任意区间 [l,r] 的和 = s[r] - s[l-1]
    for (int i = 1; i <= n; i++) s[i] = s[i - 1] + a[i];

    // 差分：区间 [l,r] 整体加 v，O(1) 完成
    // d[l] += v; d[r+1] -= v;  最后对 d 求前缀和即得实际增量
    while (q--) {
        int l, r, v; cin >> l >> r >> v;
        d[l] += v; d[r + 1] -= v;
    }
    for (int i = 1; i <= n; i++) {
        d[i] += d[i - 1];   // 差分数组前缀和 = 该位置总增量
        cout << a[i] + d[i] << " \n"[i == n];
    }
    return 0;
}

实数二分模板

求实数答案时用 double，边界不靠 ±1 收缩，而是用精度 ε 控制结束条件。

#include <bits/stdc++.h>
using namespace std;
const double eps = 1e-7;

bool check(double x) { return true; }   // 实数判定函数（按题意写）

int main() {
    double lo = 0, hi = 1e9, ans = lo;
    while (hi - lo > eps) {
        double mid = (lo + hi) / 2;
        if (check(mid)) { ans = mid; lo = mid; }   // 可行：往大试
        else             { hi = mid; }            // 不可行：往小收
    }
    cout << fixed << setprecision(6) << ans << "\n";
    return 0;
}

四、对拍与调试方法

当代码在样例上过了却 WA，或怀疑自己写法时，用对拍：写一个「暴力/直观版」和一个「高效版」，用大量随机小样例对比两者输出，谁不一致就是 bug。

手段做法
造小样例手动构造 1~3 个极小输入，用纸笔算出正确答案，核对程序输出
极端数据测 n=1、全相同、全逆序、最大值/边界值，防越界与特判遗漏
随机对拍写随机数据生成器 + 暴力解 + 你的解，脚本循环跑，输出不同即停
打桩输出关键步骤加临时打印，观察中间变量是否符合预期，调完记得删
对拍思路：随机生成器造数据 → 分别喂给「暴力程序」和「你的程序」→ 比较两个输出文件，一旦不同就把这组数据单独拎出来手算定位 bug。

五、易错点清单

易错点说明 / 对策
int 溢出结果可能超 2×10⁹ 时用 long long；乘法先转 long long 再算
数组开小按数据范围多开余量（如 n≤1e5 开 1e5+5），别卡着上界开
多测不清空多组数据时，每组前把数组 / 计数器 / vis 重新初始化干净
0 / 1 下标混用全程统一一种下标习惯，前缀和类常用 1-based 省掉越界判断
边界越界d[r+1]、s[l-1]、循环终点等容易越界，逐个核对
浮点误差实数比较别用 ==，用 < eps 判断；必要时用 long double

六、提交规范

参照站点 day1 的提交规范，简要重述：

提交前自查：① 用 ios::sync_with_stdio(false); cin.tie(0); 加速输入；② 确认输入输出格式（换行、空格、是否多组）与题目完全一致；③ 删干净调试用的临时打印；④ 确认数组大小 / 数据类型够装；⑤ 边界样例手动过一遍再交。
