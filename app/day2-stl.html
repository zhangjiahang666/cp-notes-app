day2 · 上午 —— STL 核心知识点

map · set · vector · 队列与栈 · 练习与要求

3.1 map 系列

知识点核心要点复杂度
map 核心特性红黑树，键值对，键唯一、默认升序，自带排序去重，规避大数值计数数组 MLE增删查 O(logN)
map 查找与遍历upper/lower_bound 统计出现次数；auto 遍历 first=键 second=值O(logN)
unordered_map无序，平均 O(1)O(1) 平均

⚠️ 注意事项：键不可修改、值可修改；自定义类型作键需比较函数；查找返回 end 代表未找到，禁止访问 end 内容；unordered_map 不支持排序 / 二分 / 下标访问。

3.2 set 系列

知识点核心要点复杂度
set 核心特性单元素存储，自动去重、升序插入 O(logN)
set 最值获取begin() 取最小，end() 回退一位取最大O(1)
multiset允许键重复的版本，了解基础即可O(logN)

⚠️ 注意事项：存储成对数据用 map、单个用 set；操作前校验非空避免空集合访问错误。

3.3 vector

知识点核心要点复杂度
vector 核心特性动态数组，无需固定长度，随机访问，自动扩容，规避静态数组 MLE/RE尾部插入删除 O(1)

⚠️ 注意事项：无法自动排序，可直接调 sort/reverse 等通用算法。

3.4 队列与栈

容器核心特性操作
队列先进先出，广搜核心配套；仅访问队头队尾push 队尾、pop 队头、front/back、empty/size
双端队列两端可插入删除首尾 push/pop
栈先进后出，仅访问栈顶push 栈顶、pop 栈顶、top

⚠️ 注意事项：队列不支持删队尾；队列空即广搜结束；访问空队列首尾报错；栈 pop 仅作用于栈顶。
