day1 · 下午 —— 核心工具与四道例题

提交规范 · map / set / bound 二分 · 作业要求 · 四道例题解析

1.1 提交规范

知识点核心要点
调试操作规范代码运行自动检索目录下 .in 文件生成 .out 文件，对比 .out 与标准 .outs 校验结果
时间分配要求禁止死磕单题，合理规划答题顺序，避免后续无时间作答
提交文件大小代码文件不得超过 100 KB，正常代码仅数百字节

1.2 map 容器

知识点要点复杂度
map 基础属性C++ 关联容器，红黑树实现，键值对存储，键唯一、自动升序O(logN)
map 常用操作count 判键存在；[] 插入或改值；insert 键存在则失败；erase 删键O(logN)
map 适用场景字符串作索引的去重、统计，规避桶数组索引范围不足O(logN)

1.3 set 容器

知识点要点复杂度
set 基础属性与 map 同底层，仅存唯一键、无值，自动去重排序O(logN)
set 适用场景仅需去重、排序时逻辑更简洁O(logN)

1.4 bound 二分

知识点要点
基础规则二分前提序列有序 / 单调；lower_bound 返回第一个 ≥ 目标，upper_bound 返回第一个 > 目标
数组场景返回迭代器减数组首地址得下标；二者差值 = 目标出现次数，差值为 0 判不存在
容器场景map/set 自带对应方法，无需传序列范围

1.5 作业要求

知识点核心要点
复习资料核心笔记上传至国庆 B 班队一比赛页面，可下载巩固
作业完成改错作业，携带思考结果咨询，禁止无思考提问
应试技巧由数据范围反推时间复杂度，合理使用骗分技巧

1.6 四道例题解析

题目题目规则解法要点数据结构复杂度
校园打卡题打卡有效 8:00-22:00 分时段计分，同人仅留最早有效记录，输出总分与字典序最小最高分map 存学号-得分，仅首次出现计分，重复忽略mapO(NlogN)
机器人扫地题两端墙中间 n 格走廊，机器人碰墙 / 灰尘格反转，灰尘清扫后永久变干净，求清扫全部灰尘总秒数暴力 O(n²) 仅过前 8 点得约 45 分；灰尘入 set + 墙作哨兵，跳转最近灰尘，删当前反转方向set + 二分O(nlogn)
村庄朋友统计题同校距离 ≤K1、不同校距离 ≤K2 为朋友，统计每人朋友数，数据 5×10⁵按坐标排序后二分定位距离范围，结合学校去重排序 + 二分O(NlogN)
万能密钥题N 个长度 M 互不相同 01 串，生成与每个密钥至少一位相同的万能密钥，输出任意一个密钥取反入 set，遍历 0~2²⁰，首个不在 set 的值为答案setO(2²⁰)
