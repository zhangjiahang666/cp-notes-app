专题 · 字符串

字符串哈希（滚动哈希）· KMP 模式匹配 · Trie 字典树 —— 三大高级字符串算法

本页只整理高级字符串算法；string 的基础操作（find / substr / replace 等）见「STL容器」页，此处不再重复。

一、字符串哈希（滚动哈希）

把一个字符串按「基数 B 的多项式」映射成一个整数：h = s₁·B^(n-1) + s₂·B^(n-2) + … + sₙ。预处理出前缀哈希后，任意一段子串的哈希都能 O(1) 取出，于是两段子串是否相等只需比两个整数。

关键点

要点说明
选基数B 取 131 / 13331 等奇数，避开常见自然冲突
取模方式推荐 unsigned long long 自然溢出（自动对 2⁶⁴ 取模），写起来最短；要求低冲突可双哈希（两个基数+模数各算一遍）
区间哈希公式s[l..r] 的哈希 = h[r] − h[l−1]·p[r−l+1]，其中 p[i]=B^i 预处理
复杂度预处理 O(n)，每次区间取哈希 O(1)
典型应用多段子串快速判等、判回文（正串哈希与反串哈希比较）
 
#include <bits/stdc++.h>
using namespace std;
typedef unsigned long long ull;
const ull B = 131;          // 基数，常用 131 / 13331
const int N = 1000005;
ull h[N], p[N];             // h[i]: 前缀哈希; p[i]: B^i

void build(const string &s) {
    p[0] = 1;
    for (int i = 1; i <= (int)s.size(); i++) {
        h[i] = h[i - 1] * B + s[i - 1];   // 自然溢出即对 2^64 取模
        p[i] = p[i - 1] * B;
    }
}
// 取 s[l..r]（1-indexed，闭区间）的哈希值
ull get(int l, int r) {
    return h[r] - h[l - 1] * p[r - l + 1];
}
int main() {
    string s; cin >> s;
    build(s);
    int q; cin >> q;                 // 询问多段子串是否两两相等
    while (q--) {
        int l1, r1, l2, r2; cin >> l1 >> r1 >> l2 >> r2;
        cout << (get(l1, r1) == get(l2, r2) ? "Yes" : "No") << "\n";
    }
    return 0;
}
判回文：正跑一遍 build，再把字符串反转后跑一遍，比较 get(l,r) 与反串对应区间的哈希是否相等即可 O(1) 判定某段是否回文。
哈希是「概率正确」：极端数据可能被构造出碰撞。要求绝对正确时用双哈希（两组 B/模数）同时比对，或退回 KMP。

二、KMP 模式匹配

在一个长文本串 s 中找模式串 p 的所有出现位置。朴素匹配每次失配都把 p 整体右移一位、指针回退，最坏 O(n·m)；KMP 利用 next 数组让失配时只回退「p 内部」的指针，s 的指针永不回退，做到 O(n+m)。

next 数组的含义

nxt[i] = 模式串前 i 个字符构成的子串中，最长的相等真前后缀长度（既是前缀又是后缀、且不等于自身的最大长度）。它告诉我们：当前第 i 个字符失配时，p 的指针应该跳到哪个位置继续比，而不是从 0 重来。

步骤做法
求 next对 p 自身跑一遍「自匹配」：i 从 2 扫到 m，失配时 j = nxt[j] 往前跳，直到能接上
匹配过程s 的指针 i 单调前进；p 的指针 j 失配时 j = nxt[j]；j == m 即找到一次，输出位置后 j = nxt[j] 继续找重叠出现
复杂度求 next O(m)，匹配 O(n)，合计 O(n+m)
 
#include <bits/stdc++.h>
using namespace std;
const int N = 1000005;
int nxt[N];   // nxt[i]: 模式串前 i 个字符子串的最长相等真前后缀长度

// 求模式串 p 的 next 数组（p 下标按 1 理解，字符用 p[i-1] 取）
void build_next(const string &p) {
    int m = p.size();
    nxt[1] = 0;
    for (int i = 2, j = 0; i <= m; i++) {
        while (j > 0 && p[i - 1] != p[j]) j = nxt[j];  // 失配就往前跳
        if (p[i - 1] == p[j]) j++;
        nxt[i] = j;
    }
}
// 在文本串 s 中匹配模式串 p，输出所有出现的起始位置（1-indexed）
void kmp(const string &s, const string &p) {
    int n = s.size(), m = p.size();
    build_next(p);
    for (int i = 1, j = 0; i <= n; i++) {
        while (j > 0 && s[i - 1] != p[j]) j = nxt[j];
        if (s[i - 1] == p[j]) j++;
        if (j == m) {                  // 匹配成功一次
            cout << i - m + 1 << "\n"; // 本次出现的起始位置
            j = nxt[j];                // 继续找可能的重叠出现
        }
    }
}
int main() {
    string s, p; cin >> s >> p;
    kmp(s, p);
    return 0;
}
记忆口诀：next 求的是「p 自己跟自己匹配」，匹配 s 时只是把同一段逻辑再跑一遍——两段代码结构几乎一样。

三、Trie 字典树

一棵多叉树：根节点为空，每条边上挂一个字符。从根走到某个节点，路径上的边字符连起来就是一个字符串；多个字符串共享相同的前缀（相同的那一段只存一份）。

关键点

操作做法
插入从根出发逐字符走；某字符对应的子节点不存在就新建；走到末尾在该节点 cnt++（词频）
查询（精确词频）沿字符走到底；中途断了说明没插过，返回 0；走到尾返回该节点 cnt
前缀查询沿前缀字符走到对应节点；中途断了说明没有以该串为前缀的单词；走到尾后其子树内单词数即匹配前缀的数量
复杂度插入/查询都是 O(串长)；空间 O(所有字符串总长度 × 字符集大小)
 
#include <bits/stdc++.h>
using namespace std;
const int N = 1000005;        // 节点总数上限 = 所有字符串总长度
int ch[N][26], cnt[N], tot = 1;   // ch: 子节点; cnt: 单词结尾计数; 根=1

void insert(const string &s) {
    int u = 1;
    for (char c : s) {
        int v = c - 'a';
        if (!ch[u][v]) ch[u][v] = ++tot;  // 没有该边就新建节点
        u = ch[u][v];
    }
    cnt[u]++;                     // 在单词结尾记录一次
}
// 查询单词 s 出现次数（精确匹配）；中途断了即未插入过
int query(const string &s) {
    int u = 1;
    for (char c : s) {
        int v = c - 'a';
        if (!ch[u][v]) return 0;
        u = ch[u][v];
    }
    return cnt[u];
}
int main() {
    int n; cin >> n;             // op=1 插入，op=2 查询词频
    while (n--) {
        int op; string s; cin >> op >> s;
        if (op == 1) insert(s);
        else cout << query(s) << "\n";
    }
    return 0;
}
只查词频时用 cnt；要统计「有多少单词以某前缀开头」，需要在前缀末尾节点再累加其子树的 cnt（DFS 求和）。字符集大时把 ch[ ][26] 换成 map<int,int> 或动态开点。

四、三者怎么选（速记表）

你的需求选谁为什么
多段/海量子串快速判等、判回文字符串哈希O(n) 预处理 + O(1) 区间比对；代价是极小概率碰撞（概率正确）
在一个文本里找一个模式串的全部出现位置KMP精确匹配、无歧义，O(n+m)，s 的指针不回退
多个字符串的前缀查询、词频统计Trie共享前缀只存一份，查询沿字符走树，天然按前缀组织
一句话：哈希「快而近似」，KMP「精确单串匹配」，Trie「多串按前缀组织」。判等选哈希、找模式串选 KMP、按前缀/词频组织多串选 Trie。
