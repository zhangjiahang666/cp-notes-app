STL 容器与字符串操作专题

vector · stack · queue · set · map · 字符串常见操作（源自 PDF 手册整理）

一、五大容器总览

容器底层结构核心特性时间复杂度
vector动态数组随机访问、自动扩容随机访问 O(1)
stack适配器先进后出 (LIFO)push/pop O(1)
queue适配器先进先出 (FIFO)push/pop O(1)
set红黑树有序不重复集合增删查 O(log n)
map红黑树有序键值对增删查 O(log n)

二、vector —— 动态数组

操作代码复杂度
尾部插入v.push_back(x) / 推荐 v.emplace_back(x)O(1) 均摊
尾部删除v.pop_back()O(1)
随机访问v[i] / v.at(i)O(1)
大小 / 判空v.size() / v.empty()O(1)
首 / 尾元素v.front() / v.back()O(1)
清空v.clear()O(n)
替换内容v.assign(n, val)O(n)
交换v.swap(v2)O(1)

定义：vector<type> v;；二维 vector<vector<int>> v(n, vector<int>(m,0))。初始化：v={1,2,3}、v(n+1)（n+1 个 0）、v(n,1)（n 个 1）。遍历：下标 / for(auto x:v) / 迭代器。常用算法：sort（升/降序）、reverse、lower_bound。

三、stack —— 栈（LIFO）

操作代码说明
入栈stk.push(x)元素加入栈顶
出栈stk.pop()删除栈顶（无返回值）
取栈顶stk.top()获取栈顶元素
大小 / 判空stk.size() / stk.empty()empty 为 true 表示空栈

数组模拟栈：int stk[N]; int top=0; 入 stk[++top]=x; 出 if(top>0) top--; 查 if(top>0) cout<<stk[top]; 清空 top=0;。⚠️ pop/top 前必须非空，否则 RE。

应用场景

场景思路要点
括号匹配左括号入栈，遇右括号弹栈比对不匹配 / 栈空 / 结束栈非空 → 不合法
表达式求值（后缀）遇数字入栈，遇运算符弹两个数运算后压回后缀表达式天然适合栈
验证出栈序列模拟入栈，栈顶等于出栈序列头则弹出判断能否得到给定出栈序列
单调栈维护栈内元素单调（递增 / 递减）求左右第一个更大 / 更小元素

推荐题单：括号匹配、后缀表达式求值、出栈序列合法性、柱状图中最大矩形（单调栈）、每日温度。

四、queue —— 队列（FIFO）

操作代码说明
入队q.push(x)元素加入队尾
出队q.pop()删除队头（无返回值）
取队头 / 队尾q.front() / q.back()查看队首 / 队尾元素
大小 / 判空q.size() / q.empty()—

数组模拟队列：const int N=100010; int q[N]; int h=1,t=0; 入 q[++t]=x; 出 h++; 队头 q[h]; 队尾 q[t]; 大小 t-h+1; 清空 h=1,t=0;。⚠️ front/back/pop 前必须非空。双端队列 deque：push_front / push_back / pop_front / pop_back（常数大，慎用）。应用：BFS、任务调度。

五、set —— 有序集合

操作代码说明
插入s.insert(x)不存在则插入
存在查询s.count(x)存在返回 1，否则 0
查找迭代器s.find(x)不存在返回 end()
删除值 / 迭代器s.erase(x) / s.erase(it)—
最小值 / 最大值*s.begin() / *s.rbegin()取前先判空
二分s.lower_bound(x) / s.upper_bound(x)≥ x / > x

定义：set<int> s;、set<string>、set<pair<int,int>>、set<int> s[100005];；降序 set<int, greater<>> s;。⚠️ 键类型须支持 < 运算符；自定义类型需比较函数；迭代器操作前判空否则 RE。变种：multiset（可重复）、unordered_set（无序 O(1)）。

六、map —— 有序键值对

操作代码说明
插入 / 修改mp[x] = y;键不存在则插入，否则修改
键存在查询mp.count(x)存在返回 1，否则 0
删除键mp.erase(x)删除键为 x 的元素
键值数量 / 清空mp.size() / mp.clear()—

定义：map<key_type, value_type> mp;；如 map<string,int>、二维 map<int,map<int,int>>。遍历推荐 for(auto it:mp) it.first / it.second。典型应用：频次统计（元素小用数组 cnt[x]++，范围大 / 字符串用 map）。⚠️ 键类型须支持 < 运算符。变种：unordered_map（无序 O(1)，不支持二分）、multimap（键可重复）。

七、速记口诀

vector：动态数组，尾部插入最快，随机访问 O(1)
stack：弹夹模型，先进后出，只碰栈顶
queue：排队模型，先进先出，只碰两头
set：自动排序，不重复，红黑树 O(log n)
map：键值对，键唯一，自动按键排序
