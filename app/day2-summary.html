总体概览

day2 上午覆盖了 STL 核心容器（map / set / vector / 队列栈）与贪心算法、前缀和；晚上进行了四道习题的解题思路讲评，并布置了 20 道题的练习计划。

核心知识点一览

主题关键内容复杂度
map红黑树，键唯一自动升序；upper/lower_bound 统计O(logN)
set单元素自动去重升序；begin()/end() 取最值O(logN)
vector动态数组自动扩容，尾部插入删除O(1) 尾部
队列 / 栈队列先进先出、栈先进后出；双端队列两端可操作O(1)
贪心局部最优解 + 反证法；找零 / 排队接水 / 合并果子O(n)~O(nlogn)
前缀和一维 S[r]-S[l-1]；二维容斥公式；枚举优化O(1) 查询

习题讲评要点

  • Plant 装箱：纯模拟，特判最后一个箱子；不可贪心排序。
  • 列队还原：用 list insert；字符串方案会因多位数偏移出错。
  • 格格临界：暴力 O(n⁴) 拿 40 分；哈希优化为 O(n²) 满分。
  • 提高组难题：栈 + 贪心维护最优解，暂以动图辅助理解。
