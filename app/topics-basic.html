一、一维数组

数组是连续内存的相同类型元素集合，下标从 0 开始。竞赛常开成全局定长数组（int a[N]），并习惯用 1 下标书写，越界风险低、好对齐题意。

操作写法 / 要点
定义int a[100005];；全局数组默认初始化为 0，局部数组必须手动清零
读入双层循环即可 for (int i=1;i<=n;i++) cin>>a[i];
遍历下标遍历 for (int i=0;i<n;i++)；范围 for for (int x : a)
累加 / 最值先初始化再累加；求和注意范围，必要时换 long long
 
#include <bits/stdc++.h>
using namespace std;
const int N = 100005;
int a[N];

int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];   // 1 下标，竞赛常用
    long long sum = 0;
    for (int i = 1; i <= n; i++) sum += a[i];   // 累加注意范围
    int mn = a[1], mx = a[1];
    for (int i = 1; i <= n; i++) {
        mn = min(mn, a[i]);
        mx = max(mx, a[i]);
    }
    cout << sum << " " << mn << " " << mx << "\n";
    return 0;
}
全局大数组（如 10⁶ 以上）避免开在 main 内部栈上，否则会栈溢出，应放函数外做全局变量。

二、二维数组

二维数组是「数组的数组」，对应矩阵，用 a[i][j] 访问第 i 行第 j 列。未显式初始化的元素自动为 0。

操作写法 / 要点
定义int a[105][105];；初始化 {{1,2,3},{4,5,6}}，只写前面则其余补 0
行遍历固定行号 i，遍历列 j：for (int j=1;j<=m;j++) a[i][j]
列遍历固定列号 j，遍历行 i：for (int i=1;i<=n;i++) a[i][j]
边缘判断i==1 || i==n || j==1 || j==m
矩阵转置b[j][i] = a[i][j]，行列互换
 
#include <bits/stdc++.h>
using namespace std;
const int N = 105;
int a[N][N];

int main() {
    int n, m; cin >> n >> m;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) cin >> a[i][j];
    long long rowSum = 0;
    for (int j = 1; j <= m; j++) rowSum += a[1][j];      // 第 1 行
    long long colSum = 0;
    for (int i = 1; i <= n; i++) colSum += a[i][1];      // 第 1 列
    long long edge = 0;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            if (i == 1 || i == n || j == 1 || j == m) edge += a[i][j];
    cout << rowSum << " " << colSum << " " << edge << "\n";
    return 0;
}

三、蛇形方阵与方向数组

蛇形（螺旋）方阵是「按方向走、碰壁就转向」的典型模拟。核心套路是方向数组 + 越界/已填检测：定义上/下/左/右四个方向的位移量，每走一步前检查下一步是否合法，不合法就顺时针转向。

方向dx（行变化）dy（列变化）
右0+1
下+10
左0-1
上-10
 
#include <bits/stdc++.h>
using namespace std;
const int N = 20;
int a[N][N];
int dx[4] = {0, 1, 0, -1};   // 右、下、左、上
int dy[4] = {1, 0, -1, 0};

int main() {
    int n; cin >> n;
    int x = 1, y = 1, dir = 0;
    for (int num = 1; num <= n * n; num++) {
        a[x][y] = num;
        if (num == n * n) break;              // 填完最后一格即停
        int nx = x + dx[dir], ny = y + dy[dir];
        while (nx < 1 || nx > n || ny < 1 || ny > n || a[nx][ny] != 0) {
            dir = (dir + 1) % 4;             // 越界或已填就转向
            nx = x + dx[dir]; ny = y + dy[dir];
        }
        x = nx; y = ny;
    }
    for (int i = 1; i <= n; i++, cout << "\n")
        for (int j = 1; j <= n; j++) cout << setw(3) << a[i][j];
    return 0;
}
方向数组 dx/dy 是通用工具：网格题、迷宫、走格子、八连通判断都靠它，把「四个方向」写成循环而不是四遍 if。

四、字符串基础语法

string 可看成 char 的可变长数组，支持下标访问、拼接、比较（字典序）。更全的函数清单见 STL 容器专题，这里只记语法要点。

类别写法说明
拼接s + t / s + char返回新字符串，不修改原串
长度s.size() / s.length()返回无符号整数
查找s.find("xx")返回首次出现下标；找不到返回 string::npos
截取s.substr(pos, len)从 pos 起取 len 个；省略 len 则取到末尾
反转 / 排序reverse(begin,end) / sort(begin,end)直接改原串，返回 void
类型转换to_string(n)、stoi(s)、stoll(s)数字↔字符串
整行输入getline(cin, s)读含空格的一行；先 cin.ignore() 清掉残留换行
 
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s = "hello";
    string g = s + " " + "world";        // 拼接
    cout << g << " len=" << g.size() << "\n";
    int p = g.find("world");              // 查找
    if (p != string::npos) cout << g.substr(p, 5) << "\n";   // 截取
    reverse(g.begin(), g.end());          // 反转
    int x = stoi("1234");                 // 字符串转整数
    string u = to_string(12) + "34";     // 整数转字符串
    for (char &c : s) c = toupper(c);     // 改字符要加引用
    cout << s << " " << x << " " << u << "\n";
    return 0;
}
字符串比较 < > == 默认按字典序（逐位比 ASCII）：'0'~'9' < 'A'~'Z' < 'a'~'z'，前缀相同则短的更小。

五、字符串计数与打标记

面对「统计字符出现几次 / 某个字母是否出现过」这类问题，开一个计数数组即可：用 c - 'a' 把字符映射成下标，遍历一遍字符串完成统计，O(n) 且空间 O(1)。

映射下标范围适用
c - 'a'0~25小写字母
c - 'A'0~25大写字母
c - '0'0~9数字字符转真实数字
c（ASCII）0~127通用字符 / 打标记
 
#include <bits/stdc++.h>
using namespace std;
int cnt[26];          // cnt[i]: 字母 i 出现的次数
bool seen[26];        // seen[i]: 字母 i 是否出现过

int main() {
    string s; cin >> s;
    for (char c : s) {
        cnt[c - 'a']++;          // 字符映射到下标 0~25
        seen[c - 'a'] = true;
    }
    for (int i = 0; i < 26; i++)
        if (seen[i]) cout << char('a' + i) << ":" << cnt[i] << " ";
    cout << "\n";
    return 0;
}
打标记与计数是同一套思路：bool vis[] 记「是否到过」，int cnt[] 记「到过几次」；大数按字符串逐位处理时用 s[i] - '0' 取出真正数字再运算。

六、环状字符串与取模处理

当字符串被看作环形（末位接回首位）时，越界下标用取模回到开头：长度 n，第 k 个位置就是 (start + k) % n。星空一类「超大数只能当字符串处理」的题，则用逐位累加 s[i] - '0' 绕开整型范围限制。

#include <bits/stdc++.h>
using namespace std;

int main() {
    string s; cin >> s;
    int start, m; cin >> start >> m;    // 从第 start 个字符起顺时针取 m 个
    int n = s.size();
    string out;
    for (int i = 0; i < m; i++)
        out += s[(start - 1 + i) % n];  // 取模越过末尾回到开头
    cout << out << "\n";
    return 0;
}
下标取模的通用式 (i + k) % n 可直接平移环形位置；写成 ((i % n) + n) % n 还能兼容负数下标，避免方向反向时出现负索引。
速记：数组定长开全局、用 1 下标；二维行/列遍历靠「固定一维」；走格子/螺旋用方向数组 dx/dy 碰壁转向；字符串记 find/substr/to_string；计数打标记靠 c-'a' 映射；环形一律取模 % n。
