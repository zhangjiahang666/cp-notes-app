总体概览

本次集训覆盖了核心容器工具（map / set / bound 二分）、STL（map / set / vector / 队列 / 栈）、贪心算法（局部最优 + 反证法）与前缀和（一维 / 二维），并通过 4 道例题与 20 道练习题将知识点落地。

核心知识点一览

主题关键内容复杂度
map红黑树，键值对，键唯一自动升序；count / [] / insert / eraseO(logN)
set与 map 同底层，仅存唯一键，自动去重排序；begin()/end() 取最值O(logN)
bound 二分lower_bound ≥目标，upper_bound >目标；二者差 = 出现次数O(logN)
vector动态数组，自动扩容，尾部插入删除O(1) 尾部
队列 / 栈队列先进先出、栈先进后出；双端队列两端可操作O(1)
贪心局部最优解 + 反证法；找零 / 排队接水 / 合并果子O(n)~O(nlogn)
前缀和一维 S[r]-S[l-1]；二维容斥公式；枚举优化，常配贪心O(1) 查询

方法论与应试要点

  • 贪心必须证明：先找局部最优解，再用反证法验证；特殊面额组合（50/30/20 找 60）可能失效。
  • 得分核心在策略与证明，不在代码：贪心题型重点推导策略，而非纠结写法。
  • 算法靠理解推导，不靠死记公式：前缀和公式可通过画图推导，无需背诵。
  • 时间分配：禁止死磕单题，合理规划答题顺序；由数据范围反推时间复杂度。
  • 存储选型：数据范围大（如学校编号 10¹⁹）用 map 规避数组 MLE。
  • 提交规范：对比 .in 生成的 .out 与标准结果；代码文件 ≤ 100 KB。

课后练习

  • 基础验证：排队接水、合并果子（暴力 / 前缀和 / 数学三种实现）。
  • 必做巩固：海底高铁、积水面积、激光炸弹、加深矩形（检验前缀和）。
  • STL 专项：5 道 STL 纯模板题，30-60 分钟。
  • 题单：20 道练习题（栈、队列、集合、前缀和、差分、NOIP/USACO、贪心）。
