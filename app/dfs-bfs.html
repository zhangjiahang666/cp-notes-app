一、深搜（DFS · 递归）

本质是暴力枚举，采用单条路径走到底，对应搜索树先序遍历；遇到死路就回溯换路。⚠️ 未明确边界条件会导致递归无限触发崩溃。

实现要素要点
标记数组二维 vis[][] 防止路径绕圈
方向数组四方向 dx={-1,1,0,0}, dy={0,0,-1,1}；八方向
边界校验越界直接 return / continue
回溯规则路径探索完取消标记，支持多路径复用节点；无回溯会计数错误、死循环
计数全局变量累计方案数 ans++

代码骨架

步骤代码
到终点累加if(x==tx && y==ty){ ans++; return; }
遍历四方向for(i=0;i<4;i++){ nx=x+dx[i]; ny=y+dy[i]; }
边界 / 障碍校验if(越界 || 障碍 || vis[nx][ny]) continue;
标记 + 深入vis[nx][ny]=1; dfs(nx,ny);
回溯取消标记vis[nx][ny]=0;

适用：全排列、迷宫路径方案数统计（N 值较小）等枚举类问题。

二、广搜（BFS · 队列）

本质是暴力枚举，采用水波纹逐层铺开，依托队列先进先出（FIFO）维护当前层级；节点出队不重复处理，队空即遍历完成，无回溯。

实现要素要点
方向数组四方向、八方向、特殊方向（马走日）；提前核对避免写错
边界校验严格校验坐标边界
数据存储结构体封装坐标 + 步数；步数数组与标记数组合并亦可
初始化未可达节点默认 -1

代码骨架

步骤代码
结构体struct Node{ int x,y,step; };
入队起点queue<Node> q; q.push({sx,sy,0}); dis[sx][sy]=0;
逐层扩展u=q.front(); q.pop(); 遍历四方向
记录步数if(未访问) { dis[nx][ny]=u.step+1; q.push({nx,ny,u.step+1}); }

适用：迷宫最短路径、最小步数、马的遍历等经典题。

三、深搜与广搜对比

维度深搜 DFS广搜 BFS
遍历方式递归 · 单条路径走到底（先序）队列 · 水波纹逐层铺开
回溯需要（取消标记复用节点）不需要
求什么方案数、枚举所有可能最短路径 / 最小步数
数据维护全局变量累计 ans结构体 + 队列；dis 数组
难度较难（递归易混）较易（模板性强）
典型题全排列、迷宫路径计数迷宫最短路径、马的遍历

相同点：都有边界条件避免递归无限爆炸；都配四方向 dx/dy；都需标记已走位置避免重复遍历。

四、学习方法

核心一句话：深搜和广搜本质都是暴力搜索，只是求的东西不一样。

  • 对比记忆：深搜 = 递归 / 求方案数 / 需回溯；广搜 = 队列 / 求最短路径 / 无回溯，其余逻辑高度重合。
  • 阶段要求：优先完成模板类题目暴露问题，剩余 25 天周期内逐步适配非模板题型。
  • 难点提示：两类算法核心难点是隐含边界条件的识别，无明确提示的非模板题需额外梳理边界规则。
