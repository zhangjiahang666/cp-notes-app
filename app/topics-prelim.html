一、进制转换

十进制转其他进制用除基取余（余数逆序拼回）；其他进制转十进制用按权展开（每一位乘位权 bⁱ 再相加）。

进制C/C++ 字面量前缀缩写示例
二进制0bbin0b1001 = 9
八进制0（注意！）oct0123 = 83，不是 123
十进制无前缀dec123
十六进制0xhex0x3F = 63

二 / 八 / 十六进制快速互转

1 位十六进制 ⇔ 4 位二进制；1 位八进制 ⇔ 3 位二进制。从低位向高位每 4 / 3 位分组，高位不足补 0，逐组替换即可。

负数的补码表示

码制正数负数
原码二进制 + 符号位 0二进制 + 符号位 1
反码同原码原码除符号位外逐位取反
补码同原码反码 + 1
计算机一律用补码存数：-x = ~x + 1。补码把减法变成加法，且 0 的表示唯一。位运算的结果也都是补码，若要看十进制值需再转回原码。

转换代码（可直接抄用）

#include <bits/stdc++.h>
using namespace std;

// 十进制 n 转 b 进制（b <= 36），返回字符串；除基取余
string dec_to_base(int n, int b) {
    if (n == 0) return "0";
    string s;
    while (n != 0) {
        int r = n % b;
        if (r < 10) s += char(r + '0');
        else        s += char(r - 10 + 'A');
        n /= b;
    }
    reverse(s.begin(), s.end());
    return s;
}

// b 进制字符串 s 转回十进制；按权展开
long long base_to_dec(const string& s, int b) {
    long long sum = 0;
    for (char c : s) {
        int d = (c <= '9') ? (c - '0') : (c - 'A' + 10);
        sum = sum * b + d;
    }
    return sum;
}

int main() {
    cout << dec_to_base(123, 2)  << "\n";   // 1111011
    cout << dec_to_base(123, 8)  << "\n";   // 173
    cout << dec_to_base(123, 16) << "\n";   // 7B
    cout << base_to_dec("7B", 16) << "\n";  // 123
    return 0;
}
十进制小数转其他进制用「乘基取整」法，整数部分正序排列；注意 0.1 这种十进制小数在二进制下是无限循环的，初赛常考。

二、位运算

所有位运算都在补码上按位进行。位运算常数极小，是初赛选择 / 代码填空的高频考点。

运算符名称规则典型用途
&按位与两位都为 1 才为 1取位、掩码
|按位或有 1 即为 1置位（把某位置 1）
^异或相同为 0、不同为 1翻转、无进位加、去重
~取反0↔1（有符号下 ~x = -x - 1）按位翻转
<<左移低位补 0x << k = x × 2ᵏ（不溢出时）
>>右移无符号高位补 0；有符号通常补符号位x >> k = ⌊x / 2ᵏ⌋（非负 x）

常用技巧速查

技巧写法说明
判奇偶x & 1结果为 1 即奇数
乘 / 除 2 的幂x << k / x >> k等价 ×2ᵏ / ÷2ᵏ，比乘除快
取第 i 位(x >> i) & 1最低位是第 0 位
置位 / 清位 / 翻位x |= (1<<i) / x &= ~(1<<i) / x ^= (1<<i)状态压缩三件套
lowbitx & (-x)取出 x 最低位的 1 对应的值（树状数组核心）
清最低位的 1x & (x - 1)用于 popcount、判 2 的幂
判 2 的幂x > 0 && (x & (x-1)) == 02 的幂二进制只有一个 1
异或交换a^=b; b^=a; a^=b;不用临时变量交换两数
异或去重所有数异或一遍成对出现的数抵消，落单的就是答案

位运算技巧集（可直接抄用）

#include <bits/stdc++.h>
using namespace std;

int lowbit(int x)              { return x & (-x); }          // 最低位的 1
int popcount(int x) {                                       // 二进制中 1 的个数
    int c = 0;
    while (x) { x &= (x - 1); c++; }
    return c;
}
bool is_pow2(int x)            { return x > 0 && (x & (x - 1)) == 0; }
int  get_bit(int x, int i)     { return (x >> i) & 1; }       // 取第 i 位
void flip_bit(int& x, int i)   { x ^= (1 << i); }            // 翻转第 i 位

int main() {
    int a = 5, b = 3;
    a ^= b; b ^= a; a ^= b;                 // 异或交换两数
    cout << a << " " << b << "\n";          // 3 5
    cout << lowbit(12)    << "\n";          // 4  (1100 & -1100)
    cout << popcount(15)  << "\n";          // 4
    cout << is_pow2(16)   << "\n";          // 1
    cout << get_bit(13, 2)<< "\n";          // 1 (1101 第 2 位是 1)
    // 状态压缩：用一个 int 的 n 位表示 n 个布尔状态
    int S = 0;
    S |= (1 << 2);                          // 把第 2 位加入集合
    cout << ((S >> 2) & 1) << "\n";          // 1
    return 0;
}
速记：& 取位、| 置位、^ 翻转 / 去重、~x = -x - 1、x & -x = lowbit、x & (x-1) 干掉最低位的 1。

三、基础数据结构常识

初赛选择 / 问题求解常考各结构的特点、复杂度、合法性判定，不要求手写实现，但要能在脑子里模拟。

结构特点常见操作复杂度初赛常考点
栈 Stack后进先出 LIFO，只在栈顶操作push/pop/top 均 O(1)入栈出栈序列是否合法；中缀 ↔ 后缀 / 前缀表达式转换
队列 Queue先进先出 FIFO，队尾入、队头出push/pop/front 均 O(1)BFS 底层结构；循环队列判空 / 判满条件
链表 Linked List节点 + 指针，不连续存储访问 O(n)，插入 / 删除 O(1)（已知位置）单链表 / 双链表遍历、指针修改顺序
树 Treen 个点 n-1 条边的连通无环图；根唯一、有层次遍历 O(n)二叉树性质：第 i 层至多 2ⁱ⁻¹ 个点、深度 k 至多 2ᵏ-1 个点；完全二叉树节点数；前/中/后序遍历互推
图 Graph点集 V + 边集 E，可有环 / 重边邻接表 O(n+m)；邻接矩阵 O(n²)握手定理 ∑deg=2|E|；拓扑排序判环；DFS / BFS 遍历序列
堆 Heap完全二叉树；大根堆父≥子、小根堆父≤子插入 / 取堆顶 / 删堆顶 O(log n)堆排序；优先队列；哈夫曼树合并过程（每次取两个最小合并）

表达式三种记法

记法运算符位置特点
中缀 a + b两操作数之间日常写法，需要括号定优先级
前缀（波兰） + a b两操作数之前无需括号，从右往左扫描用栈求值
后缀（逆波兰） a b +两操作数之后无需括号，从左往右扫描用栈求值

初赛阅读程序常给一段代码问输出，必须口算 int 溢出、数组大小、内存限制。

记忆：n 位有符号整数范围 [-2ⁿ⁻¹, 2ⁿ⁻¹-1]；无符号 [0, 2ⁿ-1]。数组内存 = 元素数 × 每元素字节数，1 KB = 1024 B，1 MB = 1024 KB。

常见 MLE 坑：栈上开大数组会爆栈（栈通常只有几 MB），大数组要开成全局；int a[1000000] ≈ 4 MB，long long a[1000000] ≈ 8 MB。

五、初赛复习提纲

按 algo-wiki 初赛篇三天节奏整理：day1 偏「前缀和 / 差分 / 二分答案」的代码手感，day2 偏「栈 / 队列 / 链表 / 堆 / 哈夫曼 / 并查集 / 单调栈」的数据结构性质，day4 偏「最短路 / MST / 图上状态压缩」的图论综合。初赛不写大题，重点是看懂代码 + 口算复杂度 + 性质判定。

阶段重点模块复习要点
day1一维 / 二维前缀和、差分、二分答案、二分判定 check()背熟 s[i]=s[i-1]+a[i]、二维 d[i][j]+=x 差分写法；二分答案模板（l≤r / l<r 两种边界）；能看出「答案单调 → 二分 check」套路
day2栈 / 队列 / 链表 / 堆 / 哈夫曼树 / 并查集 / 单调栈 / 倍增栈的合法性判定、中缀后缀互转；堆每次取两个最小合并（哈夫曼）；并查集 find / merge；单调栈求「左边 / 右边第一个更大元素」
day4Floyd / Dijkstra / SPFA、Kruskal / Prim MST、图上状压、虚拟点邻接表 / 邻接矩阵写法；Dijkstra 不能有负权；Kruskal 排序 + 并查集；能在脑子里模拟一遍 Dijkstra 松弛过程
通用进制 / 位运算 / 数据类型 / 复杂度估算本专题前四节内容；阅读程序时先口算数组大小、int 溢出、递归层数
初赛答题节奏：选择题优先用「排除法 + 性质判定」（如握手定理、2 的幂、栈合法性）；阅读程序先看主函数入口和循环边界，再补细节；完善程序先读输入输出样例，再根据上下文猜空。
速记：进制除基取余 / 按权展开；补码存一切数；位运算五件套 & | ^ ~ << >>；栈 LIFO、队列 FIFO、堆 O(log n)、树 n-1 边；int ≈ ±2.1e9，爆了上 long long。
